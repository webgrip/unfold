**OpenClaw and why `hermes claw migrate` exists.** OpenClaw is the open-source personal agent previously named Clawdbot → Moltbot (renamed after Anthropic trademark concerns, late Jan 2026), ~145k GitHub stars by Feb 2026 (https://www.cnbc.com/2026/02/02/openclaw-open-source-ai-agent-rise-controversy-clawdbot-moltbot-moltbook.html). Its creator Peter Steinberger joined OpenAI on 2026-02-15 and the project moved to a foundation (https://www.cnbc.com/2026/02/15/openclaw-creator-peter-steinberger-joining-openai-altman-says.html). Hermes launched ten days later into the same "always-on personal agent on your server" category and ships a one-command importer: "`hermes claw migrate` imports your OpenClaw (or legacy Clawdbot/Moldbot) setup into Hermes … Reads from `~/.openclaw/` by default. Legacy `~/.clawdbot/` or `~/.moltbot/` directories are detected automatically" (https://raw.githubusercontent.com/NousResearch/hermes-agent/main/website/docs/guides/migrate-from-openclaw.md); README: "If you're coming from OpenClaw, Hermes can automatically import your settings, memories, skills, and API keys" and `hermes setup` "automatically detects `~/.openclaw` and offers to migrate" (https://github.com/NousResearch/hermes-agent/blob/main/README.md). Its largest skills source is OpenClaw's ClawHub (docs skills.md §"5. ClawHub (`clawhub`)", https://clawhub.ai/).

## Part 1d — Strongest critiques

1. **Security: steady CVE stream and vendor non-response.** NVD keyword "hermes-agent" returns **39 CVEs** published 2026-04-27 → 2026-09-03 (highest CVE-2026-85105 6.9 MEDIUM, session subsystem, v0.18.0; most 2.1–5.5), e.g. CVE-2026-9366 prompt-injection scan bypass in `agent/prompt_builder.py` (2026-05-24), CVE-2026-10221 `_compress_context` (<=0.19.0), CVE-2026-11461 `resolve_session_by_title` authorization bypass "breaching tenant isolation" (<=0.12.0, 2026-06-07; SentinelOne: vendor "did not respond to disclosure attempts", no patched version cited — https://www.sentinelone.com/vulnerability-database/cve-2026-11461/), CVE-2026-84288 `HermesACPAgent.prompt` (<=0.18.2), CVE-2026-84289 `mcp_tool.list_tools`. GitHub-reviewed advisories: 10, incl. **CVE-2026-53869 HIGH** DNS rebinding bypassing Host/Origin validation on WebSocket endpoints (<0.16.0, 2026-06-17). Independent audit #7826 (2026-04-11): "default security posture is ALLOW-ALL"; terminal tool guarded "using only regex-based detection … bypassable"; no file-read deny list; "Container environments unconditionally skip all approval checks"; skill-file persistence — **still open with 0 comments**. SECURITY.md: "Hermes Agent is a single-tenant personal agent", in-process heuristics are explicitly out of scope (§3), "does not operate a bug bounty program" (https://github.com/NousResearch/hermes-agent/blob/main/SECURITY.md). CSA note 2026-05-04: https://labs.cloudsecurityalliance.org/research/csa-research-note-hermes-agent-cves-20260504-csa-styled/.
2. **Skill supply chain inherits ClawHub.** Hermes's Skills Hub pulls from ClawHub, where Koi Security found 341 malicious of 2,857 skills (335 installing Atomic Stealer; Feb 2026, https://thehackernews.com/2026/02/researchers-find-341-malicious-clawhub.html). Repello (2026-05-02): "As of May 2026 there is no public Hermes-specific malicious-skill incident on record" (https://repello.ai/blog/hermes-agent-security); searches through 2026-10-14 found none either. Hermes's scanner is regex-based; the "advisory SkillEvaluator scan … Without the binary on PATH the scan is silently skipped" (skills.md). Prompt-injection-via-memory is a documented threat class (Repello, CSA) with no incident on record; CVE-2026-10223 (`_scan_memory_content`, LOW) is the closest CVE. Issue-tracker volume: "prompt injection" 1,518 hits, "credential leak" 400, "malicious skill" 102.
