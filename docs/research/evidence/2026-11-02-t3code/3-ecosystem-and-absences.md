## Summary

- T3 Code is a free MIT-licensed "agent harness control surface": desktop (Electron), web, iOS and Android clients plus a `t3` server. It drives the coding agents already installed on a machine (Claude Code via the Agent SDK, Codex app-server, Cursor SDK, OpenCode, Grok Build, Antigravity, Pi, Muse Code, fx, any ACP Registry agent). [README](https://github.com/pingdotgg/t3code/blob/47f2c8d29e981c7723467efe137ee19e91df924e/README.md), read 2026-11-02.
- Timeline: repository created 2026-02-08; public alpha binaries from 2026-03-02; open-sourced and available to everyone 2026-03-07; v0.1.0 ("Orchestrator V2") 2026-10-15; v0.1.6 2026-10-31.
- Adoption is real: 40,060 stars, 9,010 forks, 4,138 open issues and PRs, about 2.1M installer downloads across all GitHub releases, and 137 contributors in a single release. User counts are self-reported and inconsistent: 60k (June), 100k (August), "500,000 devs" (homepage, November).
- It is a direct "GUI for CLI agents running parallel worktrees" competitor of Conductor, the Codex app, the Claude Code desktop app, Cursor 3's Agents Window, Nimbalyst (formerly Crystal), Sculptor, Vibe Kanban and Kandev.
- It is single-operator and machine-scoped. There is no issue-tracker integration on `main` (Linear and Jira PRs are still open), no Kubernetes, no A2A and no per-run money cap. Forgejo and Gitea are supported as source-control hosts, and MCP and ACP are first-class.

### Strongest critiques

1. Claude usage burns 3–5× faster than native Claude Code. Issue [#7338 "Extremely high usage"](https://github.com/pingdotgg/t3code/issues/7338) (opened 2026-08-17, the most-commented issue, 73 comments): "Usage is ~3x-5x higher than the native Claude app … Blocks work completely." Theo's reply of 2026-10-25 blames Anthropic: Agent SDK traffic is metered about 1.6–1.7× against the 5-hour window. The FAQ now concedes "all Agent SDK usage will drain your 5h limits faster than using Claude Code directly" ([faq.md](https://github.com/pingdotgg/t3code/blob/47f2c8d29e981c7723467efe137ee19e91df924e/docs/user/faq.md)). This is structural: T3 Code depends on a vendor's SDK metering and terms ([The Register, 2026-02-20](https://www.theregister.com/2026/02/20/anthropic_clarifies_ban_third_party_claude_access)).
2. Alpha-grade reliability and churn. Launch-week review: "broken tilde path resolution, missing file diff views, and no security for its web server mode" ([daily.dev / AICodeKing, 2026-03-07](https://daily.dev/posts/t3-code-another-agentic-gui-that-is-good-but-not-usable--jorrdkvkz)). Theo, 2026-08-18: "T3 Code has had its rough parts. We put it out as an early alpha for a reason." ([X](https://x.com/theo/status/2089812034573815925)). The forced V1→V2 orchestrator migration ([#14871](https://github.com/pingdotgg/t3code/issues/14871), 2026-10-02) and 771 releases in 8 months reinforce the point.
3. Slower than the underlying harness. [#695](https://github.com/pingdotgg/t3code/issues/695) (opened 2026-03-09): "T3 Code appears to be significantly slower than Codex for the same repository investigation task" (20+ min vs ~3.5 min). It was closed 2026-10-21 as fixed in PR #11678, and a maintainer could not reproduce it on 2026-09-12.
4. Remote relay fragility. The remote-first design depends on the hosted T3 Connect relay: [#16810](https://github.com/pingdotgg/t3code/issues/16810) (504 from relay, 54 comments, 2026-10-07), [#14070](https://github.com/pingdotgg/t3code/issues/14070) (endpoint provisioning fails on Windows 11, 2026-09-28), [#3746](https://github.com/pingdotgg/t3code/issues/3746) ("I keep getting failed to connect", 2026-07-06). Theo, 2026-10-20: the remote-first design "has a bad habit of turning basic feature additions into complex jigsaw puzzles" ([X](https://x.com/theo/status/2112437595733135745)).
5. Electron and resource use, plus open-source maintenance load. Electron RAM mockery: Theo's reply, 2026-10-20, "'electron used all my ram' is becoming one of my favorite IQ tests" ([X](https://x.com/theo/status/2112691243545440455)). Worktree disk use: "One user cleared 500 GB" ([faq.md](https://github.com/pingdotgg/t3code/blob/47f2c8d29e981c7723467efe137ee19e91df924e/docs/user/faq.md)). PR floods: "100 PRs a day for the first two days" despite a no-contributions policy ([video 2026-03-14](https://www.youtube.com/watch?v=l8pQeVVaqpY)), and "In retrospect it may have been stupid to open source this" ([X, 2026-08-06](https://x.com/theo/status/2085205880795210125)).

Absence: I found no Hacker News discussion thread (a `site:news.ycombinator.com` search returned only an unrelated 2013 item) and no Reddit thread through search. Not verified by direct HN or Reddit search.
