# De Vloer — name and mark

"De Vloer" and the De Vloer mark identify this project. They are trademarks of the De Vloer
project, held by its maintainers.

The software is [Apache-2.0](../../LICENSE). So are the files in this directory — but §6 of
that licence grants no rights in trade names or marks, and that carve-out is deliberate. This
page is what fills it.

Settled in [ADR 0020](../adrs/0020-the-name-and-mark-are-trademarks.md).

## You may, without asking

- Reproduce the **unmodified** mark, wordmark or lockup to refer to De Vloer — in articles,
  talks, slides, README badges, ecosystem and integration listings, comparison tables,
  screenshots.
- State truthfully that your software **works with**, **supports**, **integrates with** or
  **is built on** De Vloer.
- Link to the project using the name and mark.
- Scale the assets, and use any of the supplied colour, monochrome, white, reversed or tile
  variants.
- Redistribute an **unmodified** De Vloer as De Vloer — a distribution package, a container
  image, a chart mirror — as long as it is unmodified.

No permission request, no notification, no fee.

## You may not, without written permission

- Ship a **modified or forked** distribution under the name De Vloer or under the mark. Fork
  the code freely — Apache-2.0 says you may — but give it your own name.
- Use the name or mark in a way that implies **endorsement, affiliation, sponsorship or
  certification** by the De Vloer project.
- Use the name or mark, or anything confusingly similar, as **your own** product name, company
  name, domain name, app-store listing or social handle.
- **Alter** the mark: change its stroke width, its 22.5° arms, the position of the floor or the
  two-colour split; recolour it outside the supplied palette; rotate it; add effects; or
  combine it with another mark into a new one.
- Present the mark as the most prominent element on materials that are not the project's own,
  in a way that suggests the material comes from us.

## Using it correctly

[`README.md`](README.md) in this directory carries the construction, the palette with measured
contrast, the lockups, clearspace and minimum sizes. The short version:

- Clearspace: one stroke width on every side.
- Minimum size: 24 px for the mark (use `favicon.svg` below that), 160 px wide for the
  horizontal lockup.
- Never re-set the wordmark in a live font. Use `wordmark.svg`; it is outlined.
- Never put the ink mark on a dark ground. Use `mark-reverse.svg` or `mark-currentcolor.svg`.
