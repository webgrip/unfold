# Authorize, then start

A session is authorized when created and runs only when you choose **Start remote crew**. Close the laptop; the work continues on the server.

The session panel leads with one sentence: what is happening and what you can do next. Below it:

- **Your crew** shows each role, its state, elapsed time and findings rendered as readable text.
- **Brief · Changes · Checks · Activity** hold the objective, per-file changes, check output and the durable event stream.
- The **budget** card shows authorized, observed and reserved amounts. Unknown spend is never shown as zero.

Open panels follow the server event stream live and fall back to polling. The footer always states when the state was last observed.
