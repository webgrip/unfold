# Contributing to Unfold

Unfold is [Apache-2.0](LICENSE): what you contribute comes in under the same licence, with no CLA and no copyright assignment. [apps/unfold/CONTRIBUTING.md](apps/unfold/CONTRIBUTING.md) explains the licence terms, including the trade mark, in full.

Start with [How work on Unfold is done](docs/contributing/way-of-working.md). It covers tickets, worktrees, commits, the gates (`mise run verify`), pull requests, review and releases, for people and agents alike. Agents also read [AGENTS.md](AGENTS.md).

To report a problem, open an issue on [the forge](https://forgejo.webgrip.dev/webgrip/unfold/issues) with the Report a problem template. For a security problem, say so in the title and leave out the working details until a maintainer replies.
